# Standards: Documentation

## Minimum per project
- `README.md` (what it is, how to run, where logs are)
- `docs/` folder exists
- `docs/guides/` if the project has repeatable procedures

## When behavior changes
- Update README and any affected guides.
- If a doc is stale, mark it clearly rather than silently leaving wrong info.
